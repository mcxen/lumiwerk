# Lumiwerk UI 规范

这份文档记录浏览界面里**已经实现**的尺寸与行为约定。改动相关常量或视图时同步更新这里;
代码与文档不一致时以代码为准,并修正文档。通用的 MyGo 用法见 `mygo-ui-cheatsheet.md`,
测试与诊断约定见 `development.md`。

## 1. 布局

`appState.LayoutMode` 决定浏览区用哪个视图:

| LayoutMode | 名称 | 视图 | 说明 |
|---|---|---|---|
| 0 | 网格 | `gridView` | 定宽方格,图片 `Contain` |
| 1 | 详情 | `detailView` | 名称 / 大小 / 修改日期 三列表格 |
| 2 | 瀑布 | `waterfallView` | 多列,每张卡片按宽高比取高,绝对定位,只构建可见窗口 |
| 3 | 紧凑 | `justifiedView` | 按宽高比拼行,整行拉满宽度,图片 `Cover` |

新窗口默认「紧凑」布局、缩略图 150(`defaultLayout`、`defaultThumb`);已保存的配置沿用自己的选择。

## 2. 缩略图大小与卡片缩放

- 滑块范围 **64–512**(`ui.Slider(... 64, 512)`),默认 **150**。
- `cardScale(thumb) = clamp(thumb / 150, 0.9, 1.8)`:默认大小时为 1,最小不低于 0.9,最大 1.8。
- **随缩放变化**(乘 `cardScale`):
  - 卡片内部间距(基准 4)
  - 视频时长、来源文件夹角标:字号 10、外边距 4、内边距 1×5、圆角 3、最大宽度 180
  - 标签小圆点:大小 5、间距 2、圆角 2、外边距 4
  - 占位图标(文件夹 / 文件类型),见第 3 节
- **固定不变**:
  - 文件名与文件夹名:字号 **11**,最多两行,居中
  - 文字区高度 `flowLabel` = **30**(「无字模式」下为 0)
  - 行内重命名输入框字号 11
  - 卡片与选中框圆角 `heroThumbRadius` = 8(与打开大图的飞入动画共用,单独改会让动画起点错位)
  - 详情列表的图标(15)与文字(11、12):行高固定的紧凑列表,不受滑块控制
- 间距常量:`flowPad` 8、`flowGap` 6、`gridCellPad` 16(网格单元在缩略图外的留白)。

## 3. 占位图标

缩略图还没有、解码失败或没有封面时,卡片显示系统图标:

- 尺寸 `glyphSize(box, floor)` = `max(floor, min(box × 0.7, 160))`。`box` 在网格里是缩略图大小,
  在瀑布 / 紧凑里是卡片图片区较小的一边;`floor` 为 28(解码失败的文件为 24)。
- 例:200pt 的卡片图标 140pt;小卡片不小于 28pt;最大 160pt。
- 详情列表固定 15pt。

## 4. 缩略图加载

- 内存 LRU(`thumbLRU`,字节预算 128 MiB,键含文件的 mtime 与大小:同名文件被改写后不会命中旧图)与磁盘缓存(`diskcache.go`)按**尺寸档**取图:
  `thumbBand` 把解码边长归到 256 / 384 / 512 / 768 / 1024,避免滑块微调就重建全部缩略图。
- **命中内存缓存的缩略图必须在卡片构建的同一帧上屏**:`mediaCard` 调用 `adoptCachedThumb`,
  `loadThumb` 开头也先同步查缓存。不要让缓存命中再绕 goroutine 和 `Window.Update`,
  否则名字当帧出现、图片晚一帧,滚动时两者不同步。
- 文件夹封面的缓存键含目录内容摘要,要遍历目录才能算出,所以 `coverKeys` 记住每个文件夹上次的键:
  卡片构建时若该叠图仍在内存,当帧直接显示,后台再校验摘要,目录内容变了才替换。
- 未命中缓存时才走后台解码,完成后经 `appState.update` 回到主线程;这种首次加载的延迟是正常的。
- 预取:可见范围外多取 12 项(`thumbPrefetchExtra`),元素距视口 240pt 内也会请求
  (`thumbPrefetchMargin`)。离屏超过 5 秒且不在缓存里的位图会被释放。
- 瀑布 / 紧凑只构建滚动窗口上下各半屏(`flowOverscan` = 0.5)内的卡片。

## 5. 卡片

`mediaCard` 是网格、瀑布、紧凑共用的卡片:缩略图区 + 名称。

- 选中:`selectionChrome` 用 `SurfacePressed` 填充,圆角 8。
- 被剪切的项目整体不透明度 0.4。
- 网格卡片额外有标签点、行内重命名、悬停提示(名称与大小);紧凑 / 瀑布没有。
- 瀑布卡片在左上角显示来源文件夹,其他布局不显示。
- 文件夹有封面时用叠放图(`Contain`),没有时用文件夹图标。

## 6. 回归测试

UI 改动按 `AGENTS.md` 用 `ui.NewTester` 覆盖。与本文相关的测试:

- `thumb_sync_test.go`:缓存命中的缩略图随卡片同帧上屏;文字区固定、缩放系数随滑块;占位图标尺寸。
- `waterfall_virt_test.go`:瀑布只构建可见窗口。
- `mediacard_test.go`、`typeicon_test.go`:共用卡片与图标。
